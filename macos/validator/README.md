# macOS USB DAC Validator

Run `./build.sh` on macOS with Xcode command-line tools, Rust and a C compiler installed. It builds an Apple Silicon unsandboxed `.app` and distribution ZIP in `build/` for macOS 12 or later; install the aarch64-apple-darwin Rust target first. The worker links vendored libusb. The app uses the direct USB driver, not CoreAudio. Set `SIGNING_IDENTITY` to a Developer ID Application identity for optional hardened-runtime signing. The resulting bundle is not notarized by the build script.

Remove headphones and mute or disconnect the amplifier before starting. Start capture first, then connect one DAC. The test may emit DoP marker noise if the device does not decode DoP. The ZIP is generated on completion, cancellation or a handled failure; use **Save diagnostics** to choose its destination. Reports contain device identifiers and debug logs.

The **Include source-backed compatibility modes** option is enabled by default for validator runs. It selects the library's `SourceBacked` quirk policy, which can expose device-specific modes supported by source evidence even when they have not been verified on this host. Clear the option to use the library's strict `VerifiedOnly` default. The chosen policy is saved in the ZIP, including when the run ends before a DAC is opened. The worker also accepts `--verified-only` after the capture-directory argument for command-line runs.

macOS may already own a DAC through its USB audio driver. An ordinary claim can fail. The optional checkbox permits libusb to capture the whole device, affecting its other interfaces, and can require administrator authorization. Enable it only for the intended device; an unsuccessful claim is recorded. The app does not elevate itself or change security settings. If authorization is required, an administrator can start the worker or app in an authorized environment and the effective user ID is captured. Unplug and reconnect the DAC after the run if macOS does not restore the audio route.

For ordinary use open the app normally and leave driver capture unchecked. When a claim fails and whole-device capture is explicitly authorized, rerun the app with administrator privileges from Terminal (for example, `sudo "USB DAC Validator.app/Contents/MacOS/USB DAC Validator"`) and enable the capture checkbox. Authorization and effective identity are recorded; administrative launch should be used only for a device the operator is authorized to capture.
