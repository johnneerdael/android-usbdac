Direct USB audio. Clear evidence.

Bring direct DAC playback to your app. usbdac sends PCM, DoP or native DSD straight to the DAC over USB, follows the device clock, drives its hardware volume and tells you whether the stream is bit-perfect, with the reason when it is not.

Native DSD on the DC04U and SMSL came from a source-backed rule that the default policy does not apply. Read the hardware status · what each release checks.

Validators

Test your own DAC.

The validator apps run the exact-format playback matrix on one attached DAC and save a report ZIP with device details, test outcomes and debug logs. Every release includes both, built from the same commit as the library.
